What this result means

Where to be careful

How was the news sentiment trained?

English headlines from Benzinga were given "training labels" using the Hu & Liu and Loughran–McDonald word lists, not by a person reading them and not by checking whether the stock actually rose or fell after the news. These labels then trained a TF-IDF (single words, English stop words removed) followed by a LinearSVC.

So the model is learning to "imitate the word-list labels" rather than learning whether the news is really good for the business, and it uses only the headline, not the full article.

The reported 94.5% is "agreement with labels made from the word lists" on the 2018 check set. It is not human-verified accuracy. The softmax computed from the SVM margin scores is not a calibrated probability. This page does not run the real classifier; every example is a made-up scenario for explanation only.

"Big move" — how exactly is it defined?

On decision day t, the training target uses the return from the close of day t+1 to the close of day t+6, 5 trading days. The median forward return of all stocks on the same day is subtracted, and the absolute value of the difference is taken. If that value is above the 80th percentile, the row is labeled a big move. So both large positive and large negative deviations qualify. It is not a fixed percent price-change threshold and not a measure of intraday range.

The 10 features are first centered on the median of all stocks on the same day. A HistGradientBoostingClassifier then learns this target, and an Isotonic Regression adjusts the probabilities to match real frequencies. Training uses data before 2022, calibration uses 2022, and the test period is 2023 through October 2026. The reported AUC is 0.674 against a baseline of 20-day volatility alone, which scores 0.663. AUC is not a percentage of correct answers, and the gap from this baseline is small. The backtest does not prove it can be traded profitably.
