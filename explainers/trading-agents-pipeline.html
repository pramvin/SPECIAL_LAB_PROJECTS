TradingAgents: how the pipeline works

A multi-agent framework where one run = one ticker + one date → one rating (Buy / Overweight / Hold / Underweight / Sell). Every step is an LLM "agent" reading text written by the step before it.

Report written by reading the source code in ~/Downloads/TradingAgents-main (v0.7.1). I did not run it and did not check any of its performance claims. The debate lines shown below are not from a real run: only the structure comes from the code.

The five-point scale

Research Manager and Portfolio Manager both use the same five ratings. The Trader uses only Buy / Hold / Sell (Overweight counts as Buy, Underweight as Sell).

BuyOverweightHoldUnderweightSell REVIEW = no readable rating

If the final text has no readable rating, the code returns REVIEW, not Hold. A decision nobody can read is not recorded as a "Hold" call.

Design ideas worth noticing

Text in, text out

Agents do not share numbers. Each one gets earlier reports pasted into its prompt and writes more text. The only typed (structured) outputs are the three manager-level steps: Research Manager, Trader, Portfolio Manager, plus the Sentiment report.

Two model tiers

"Quick" model for analysts, debaters and the Trader. "Deep" model only for the Research Manager and Portfolio Manager, the two steps that decide.

Debates have a fixed length

Defaults: 1 round. Bull and Bear speak 2 turns in total. The three risk analysts speak 3 turns in total. Then a manager decides. No open-ended arguing.

Tool-loop guard

Each analyst may call tools up to 20 rounds, then is told to write its report. A model that keeps calling tools cannot run the graph forever.

Price grounding

The Market Analyst must call a "verified snapshot" tool and treat it as the source of truth for exact prices. The Trader also receives the market report so entry and stop are real price levels, not percentages.

Memory with a point-in-time rule

Past decisions are scored after a holding window, turned into a 2-4 sentence lesson, and reused. For back-tests, only lessons whose outcome was already known by that date are shown.

How it differs from PlanWise AI (my reading)

Who makes the numbers

TradingAgents: an LLM at every step, including the final rating. PlanWise: ranking and the big-move model are code and a trained model; the LLM only reads headlines and writes reasons.

Scope

TradingAgents analyses one ticker per run, with many tool calls. PlanWise ranks about 879 stocks per day, which would be too slow and costly to do this way.

Idea we could borrow

The memory loop: score each past recommendation after N days and feed a short lesson back. It is also an honest way to measure the app. This is only an idea, not a plan.
