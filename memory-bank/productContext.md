- **ปัญหา (สมมติฐาน ยังไม่มี user research):** คนรวมข้อมูล/ข่าวหุ้นเองยาก ไม่รู้ข่าวไหนเชื่อได้ ไม่รู้ต้องทำอะไรต่อ
- **วิธีแก้:** การ์ดไอเดียต่อโปรไฟล์ความเสี่ยง: เหตุผลจากตัวเลขจริง + ข่าว + stop/target (ATR) + ขนาดตำแหน่ง + การอ่านข่าวโดย AI (ป้าย "AI · Not validated", ไม่กระทบคะแนน)
- **แนวคิดเจ้าของ:** filter ตอบ "ข่าวจริง/แหล่งน่าเชื่อถือไหม" · LLM ตอบ "ดีหรือแย่ต่อหุ้น เพราะอะไร" · ข่าวน่าเชื่อเมื่อฝ่ายที่ระบุตัวตนได้พูดเอง
- **Flow:** Login → Onboarding 5 ข้อ → Trade ideas (`?h=1w|1m|3m`) → การ์ด + Top news
- **หลักความน่าเชื่อถือ:** แยก ข้อเท็จจริง / ข้อมูลผู้ใช้ / ตัวอย่าง / ผล AI · ไม่มีข้อมูล = "ไม่ทราบ" ไม่ใส่เลขปลอม
